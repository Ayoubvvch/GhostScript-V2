مُتحدث Toast والحكمة على الشاشة

إطلاق رسائل Toast مباشرة فوق أي تطبيق أو على الشاشة الرئيسية، للتواصل مع السكريبتات وإرسال عبارات أينشتاين والحكماء.

# استخدام الأمر المباشر في الشيل أو الروت:
toast "Einstein said: Imagination is everything"

# أو عبر Broadcast:
am broadcast -a com.ayoub.ghostscript2.SHOW_TOAST --es text "رسالتك"
